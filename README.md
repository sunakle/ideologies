# Атлас идеологий

Русскоязычная образовательная энциклопедия с интерактивной политической картой. Первый выпуск: **69 статей, 47 точек на карте, 22 записи без однозначных координат, 116 уникальных ссылок на источники, 14 исторических изображений для 21 статьи**.

Это расширяемая начальная редакция, а не полный перечень всех идеологий. Академическая рецензия всего корпуса не проводилась. Часть публикаций изучена по доступным аннотациям и поисковым извлечениям; ограничения указаны на сайте.

## Открыть готовый сайт

В Windows запустите `Открыть атлас.cmd`. Нужен Node.js 22 или новее. Скрипт откроет локальную копию из `dist/` без установки библиотек. Окно сервера должно оставаться открытым; Ctrl+C останавливает его. Если порт 4174 занят, выполните `node scripts/serve.mjs 4175` и откройте адрес, напечатанный в окне.

## Разработка

Нужны Node.js 22+ и npm:

```sh
npm ci
npm run dev
```

Проверка и сборка:

```sh
npm run check:data
npm run build
```

Стек: React, TypeScript, Vite, Three.js, Fuse.js, Lucide. Сайт полностью статический. Поиск работает локально; учётные записи, аналитика и внешняя база данных не используются. Шрифты пока загружаются из Google Fonts; при отсутствии сети используются системные шрифты.

## GitHub Pages

1. Создайте пустой репозиторий в своём аккаунте. Для бесплатного GitHub Pages обычно используется публичный репозиторий.
2. Загрузите содержимое этого каталога в ветку `main`. `node_modules/` и `dist/` не включаются в Git; исходники изображений в `public/images/` включаются.
3. В репозитории откройте **Settings → Pages → Source → GitHub Actions**.
4. Workflow `.github/workflows/deploy.yml` проверит данные, соберёт сайт и разместит `dist/` в Pages.
5. Откройте URL из завершившегося workflow. Адрес зависит от владельца и названия репозитория.

Статьи используют hash-маршруты, например `/#/wiki/social-democracy`: прямые ссылки не требуют перенаправлений сервера и работают внутри пути репозитория. Относительный `base` в Vite позволяет менять название репозитория без изменения кода.

## Как пополнять каталог

Все статьи находятся в `src/catalog.json`, схема — в `src/types.ts`.

- `id`: постоянный латинский slug; не меняйте его после публикации без добавления перенаправления.
- `family`: основное навигационное семейство; это не утверждение единственной принадлежности.
- `year`: приблизительный ориентир формирования, отрицательные числа — до нашей эры.
- `summary`, `ideas`, `history`, `critique`, `people`, `variants`: самостоятельный краткий обзор.
- `related`: ID существующих тематически связанных статей; это не доказанный граф происхождения.
- `coords`: `[экономика, власть, культура]` в диапазоне −10…10 либо `null`. Не назначайте точку искусственно.
- `uncertainty`: редакционный диапазон, а не статистическая погрешность.
- `placement`: объяснение выбора координат и внутренних различий.
- `sources`: конкретные HTTPS-страницы с названиями; проверяйте, что они действительно поддерживают текст.
- `checked`: дата подготовки и проверки ссылок; не свидетельство экспертной рецензии.
- `image`: необязательная иллюстрация с локальным путём, авторством, лицензией и ссылкой на источник.

Изображения добавляйте в `public/images/`, одновременно обновляя `public/images/attribution.json`. Не используйте чужие фотографии без установленного права использования. У изображений CC BY/CC BY-SA должны сохраняться авторство и ссылка на лицензию. На сайте предусмотрена явно обозначенная абстрактная иллюстрация для записей без исторического изображения.

После изменения данных выполните обе проверки выше. Проверьте также статью в браузере, поиск по её названию, связанные статьи и изображения.

## Управление

- Мышь: левая кнопка — вращение; колесо — масштаб; правая — перемещение.
- Сенсорный экран: один палец — вращение, два — масштаб и перемещение.
- Дальний масштаб объединяет точки по семействам; приближение раскрывает течения.
- В 2D видны экономика и власть; культурная ось скрыта.
- Поиск понимает названия, английские эквиваленты, синонимы, распространённые опечатки и простые русские словоформы. Точная фраза — в кавычках.
- Ctrl+K открывает поиск на страницах атласа и каталога.
- Каталог и текстовый список обеспечивают альтернативу WebGL и управлению мышью.
- Избранное, сравнение и настройка анимации хранятся в localStorage данного браузера.

## Границы первого выпуска

Нужны дальнейшее исследование региональных и малых течений, дополнительные независимые источники, иллюстрации остальных статей и экспертная проверка. Численные координаты редакционные. Проверенный генеалогический граф пока не включён. На мобильном экране карточка размещается под картой; это не отдельная нативная выдвижная панель.

Данные по преступлениям исторических режимов изложены в образовательном контексте. Историческая символика не используется как оформление бренда или одобрение движения.
